# Manual Testing Practice Project

Manual testing practice on the demo website https://www.saucedemo.com.

## What is inside

- Testing_Practice_Project.xlsx
  - Test Cases sheet: 23 test cases (login, cart, checkout, sorting and different user types)
  - Bug Reports sheet: 6 bugs with steps, expected and actual result, severity, priority, status and Jira ID
- BUG01 to BUG06 .png files: screenshots of the bugs

## Bugs found

| ID | Title | Severity | Jira |
|----|-------|----------|------|
| BUG01 | All products show the same image for problem_user | Medium | KAN-4 |
| BUG02 | Add to cart does not work for 3 products for problem_user | High | KAN-5 |
| BUG03 | Products are not sorted by price for problem_user | Medium | KAN-6 |
| BUG04 | Last Name field does not accept text on checkout | High | KAN-7 |
| BUG05 | Cart items from one user are shown to another user | Medium | KAN-8 |
| BUG06 | Finish button does not complete the order for error_user | High | KAN-9 |

## Skills practiced

- Writing test cases (ID, steps, expected and actual result, status)
- Finding and reporting bugs
- Severity and priority
- Bug tracking in Jira (To Do, In Progress, In Review, Done)
- Taking screenshots as proof
